# 大学之家 · 全国高校导航

一个轻量的全国高校导航站：按省份浏览 2919 所高等学校，支持实时搜索、组合筛选、复制学校标识码、一键访问官网。

## 数据来源

- 学校名单：[教育部《全国高等学校名单》](http://www.moe.gov.cn/jyb_xxgk/s5743/s5744/A03/202506/t20250627_1195683.html)（截至 2025-06-20，普通高等学校 2919 所 + 成人高等学校 248 所）
- 官网 URL：`CollegesChat` 域名库 + `open-edu-data` 补充 + 搜索引擎逐所补全，整体覆盖率 **99.5%**（剩余为已停办/合并、确无独立官网的院校，点击后转百度搜索校名）
- 标签：985 / 211 / 双一流 / 公办 / 民办 / 合作办学，由名单字段自动判定

## 功能

- 顶部省份胶囊锚点（自动换行）→ 平滑滚动跳转
- 实时搜索（校名 / 标识码 / 主管部门 / 所在地）
- 组合筛选（层次 / 性质 / 标签）
- 卡片：校名 + 标识码（常驻复制按钮）+ 所在地 + 标签；桌面 hover / 移动端点「i」展开主管部门、备注、官网
- 点击卡片主体 → 有官网跳官网，无官网跳百度搜索

## 本地运行

```bash
node tools/serve.js        # 启动本地静态服务器 http://localhost:8080
```

## 重新生成数据

```bash
node tools/parse.js        # 解析教育部 XLS → 基础数据
node tools/enrich.js       # 补全官网/标签 → 输出 universities.json
```

`data/website_patch.json` 是手动补全的官网映射，重跑管线不会丢失。
